# Sofrito

By this point a Design System is pretty standard tablestakes for a product group and Sofrito is ours.  Named after the [common recipe base](https://en.wikipedia.org/wiki/Sofrito) which Dorothy described as "the very base of the meal on which more flavors are built" which sounds an awful lot like the goal of a good design system!

We've built ours on [Radix UI](https://www.radix-ui.com/) using their Primitives.  It could be that we should've started from one of their Themes but we're starting basic.

# Docs

Nothing super fancy here but any good platform has to have a docs site!  So we have ours built on [Fumadocs](https://www.fumadocs.dev/) running on [Cloudflare Workers](https://www.cloudflare.com/en-gb/developer-platform/products/workers/) leveraging [Redwood SDK](https://rwsdk.com/).

It's aimed at us KAD folks but it's publicly available so if you wanted to you can certainly [take a peek](https://docs.kad-products.com/).

# Shed

Named for the ubiquitous tool shed that holds anything you might need to get the job done.  Whether it be lawn mowers, extension ladders, the random extra piece of treated 6" x 6" lumber, or shovels the shed has it all.  

Our Shed aims to be no different.  Shared modules, components, and utilities for our various apps all live here.  If it is a piece of code we want to share that isn't a workflow or in [Sofrito](./sofrito) it lands here.
